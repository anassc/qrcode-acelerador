# ⚡ Instant QR Code Generator

<img width="958" height="850" alt="image" src="https://github.com/user-attachments/assets/479ead63-de1b-4a35-85f9-a3c3fc8f9a07" />



A modern, fast, and intuitive web application to generate custom static QR codes. Simply paste your URL, pick a style, customize the colors, and get your QR code instantly—no registration required, no hidden fees, and no expiration dates.

This project was built with the assistance of the **Lovable** AI platform.

---

## ✨ Features

* **Instant Generation:** Paste your link and generate your QR code in real-time.
* **Style Templates:** Switch between a sleek "Modern" look or the traditional "Classic B&W".
* **Color Customization:** Choose from a vibrant color palette (Orange, White, Blue, Green, Purple) to match your brand.
* **Sizing Options:** Select the perfect dimension for your needs (Small, Medium, or Large).
* **Static QR Codes:** Every code generated is static, meaning it works forever and will never expire.

---

## 🚀 Tech Stack

This project was built using modern web development tools:

* **React** / **Vite**
* **Tailwind CSS** (for the sleek dark mode interface and responsive layout)
* **Lovable Dev** (the AI development platform used to build and scaffold the application)
